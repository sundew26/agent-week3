### 工作流 Studio
- 定义：本项目的全称 Workflow Studio，是一个基于 LangGraph + Vue 3 + Vue Flow 构建的可视化多 Agent 研究工作流系统，用户通过可视化画布编排并执行研究任务。
- 别名：workflow-studio、Workflow Studio

### Human-in-the-loop
- 定义：人工审核机制：工作流执行到审核节点时暂停，弹出 ReviewDialog 等待人工判断“通过”或“不通过”，通过则输出最终报告，不通过则回到搜索节点重新执行。
- 别名：人工审核、审核节点

### 检查点恢复
- 定义：利用 SQLite 持久化的 LangGraph 检查点，在工作流中断或页面刷新后从上次保存的状态继续执行，避免重复计算。
- 别名：checkpoint recovery、检查点

### 防无限循环
- 定义：工作流内置保护策略：审核→修订→搜索最多循环 3 轮，超过阈值后强制输出结果，防止工作流陷入死循环。
- 别名：max revision rounds、修订上限

### SSE 实时推送
- 定义：Server-Sent Events 流式传输机制，后端通过 sse-starlette 向前端推送工作流执行状态和 LLM 输出，前端通过 `useWorkflowSSE` composable 消费事件更新 UI。
- 别名：SSE、流式推送
