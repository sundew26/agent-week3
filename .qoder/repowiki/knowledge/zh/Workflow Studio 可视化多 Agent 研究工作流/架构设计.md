模块采用前后端分离的双工程结构：后端 `backend/app/` 以 FastAPI 为入口（`main.py`），通过 LangGraph `StateGraph` 定义研究助手工作流图（`graph.py`），节点实现位于 `nodes.py`，共享状态由 `state.py` 中的 `ResearchState` TypedDict 描述，工具函数在 `tools.py`，配置在 `config.py`；工作流编译时挂载 `AsyncSqliteSaver` 检查点并设置 `interrupt_before=['output']` 实现人工审核中断，`main.py` 暴露 `/api/workflow/start`、`/api/workflow/review`、`/api/workflow/state/{workflow_id}`、`/api/workflow/graph-structure` 四个 REST 端点，均以 `StreamingResponse` + SSE 推送 `node_start/node_end/token/tool_result/interrupted/completed/error` 事件。前端 `frontend/src/` 使用 Vue 3 + TypeScript + Vite，核心画布 `WorkflowCanvas.vue` 基于 `@vue-flow/core` 渲染固定布局的 7 个节点与边，右侧面板组件（`panels/`、`layout/SidePanel.vue`）负责输入、日志、审核弹窗与时间线；状态集中在 Pinia store `stores/workflow.ts`，SSE 连接封装在 `composables/useWorkflowSSE.ts`，类型定义统一在 `types/workflow.ts`。依赖方向单向：前端仅通过 HTTP/SSE 调用后端 API，不直接访问 LangGraph。
